# Code of Conduct

wheeljack is an open-source project maintained by Bildhaus. Participation
should be direct, constructive, and respectful.

## Expected behavior

- Discuss the work rather than attacking the person doing it.
- Give specific, actionable feedback and assume good faith.
- Respect differences in experience, identity, background, and communication
  style.
- Protect private project data, credentials, and unpublished vulnerability
  details.
- Accept maintainer decisions about scope, moderation, and project direction.

Harassment, threats, discriminatory language, sexualized attention, deliberate
disruption, doxxing, and publication of private information are not accepted in
project spaces.

Maintainers may edit or remove contributions and restrict participation when
behavior harms the project or its community. To report conduct privately,
contact a Bildhaus maintainer through a published private contact channel. Do
not use a public issue when the report would expose personal or
security-sensitive information.
